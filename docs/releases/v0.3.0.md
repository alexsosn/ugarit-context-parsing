# Ugarit Context Parsing v0.3.0

This is the first stable GitHub release of the Burns Workbooks materializer.

## What users get

- **CUC-aligned Burns module as the primary product.** `ugarit-context-parsing module` materializes Burns contextual annotations as a feature-only Text-Fabric module layered on the exact reviewed Copenhagen Ugaritic Corpus (CUC) base.
- **CSV and PDF inputs.** The same normalization, alignment, reporting, and module-writing pipeline accepts generated Workbook CSV directories or the original Workbook PDFs; PDF mode reuses the existing Workbook parser rather than maintaining a second interpretation.
- **Conservative alignment.** Burns references are parsed without guessing ambiguous columns or arbitrary lexical matches. Exact unique word and multi-word spans are selected when supported; ambiguous, unresolved, partial, out-of-CUC, and non-textual annotations remain explicitly accounted for in the report.
- **Exact CUC compatibility contract.** Materialization verifies the reviewed `DT-UCPH/cuc` commit `ad69400f5446e1c8217af01659c7c10ab00c015b`, Text-Fabric version directory `tf/0.2.8`, required-file checksums, and structural fingerprint before writing a module.
- **Context-Fabric/cfabric-mcp composition.** The CUC base and Burns feature module can be loaded as separate ordered locations without duplicating or changing the CUC warp/navigation structure.
- **Deterministic and defensive conversion.** Semantic identities, reports, module payloads, CSV/PDF discovery order, and compatibility fingerprints are deterministic. Source-root and input symlinks are rejected; failed publications leave the previous complete output intact.
- **Legacy converter retained.** `ugarit-context-parsing convert` still produces the historical standalone Burns row-slot corpus for compatibility, but it is deprecated in favor of `module`.

## Agora status

Agora currently registers only the two legacy one-source materializers:

- `burns-workbooks-csv-text-fabric`
- `burns-workbooks-pdf-text-fabric`

The reviewed CUC-aligned `module` CLI is already usable locally and through Context-Fabric/cfabric-mcp, but Agora's parent-resource execution capability was deferred from the current scope. This release does not pretend that the parent-aware module is registered in Agora, does not copy CUC into Burns output, and does not enable implicit network acquisition.

## Compatibility

- Python 3.10+
- Text-Fabric `>=13.1,<14`
- Reviewed CUC base: `DT-UCPH/cuc@ad69400f5446e1c8217af01659c7c10ab00c015b`, `tf/0.2.8`

No Burns-derived data files are attached to the release.
